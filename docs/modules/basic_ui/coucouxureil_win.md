# Coucou Xureil Module

A simple trigger node that emits "coucou mr melon".

---

## Technical Specifications

- **Inputs**: None.
- **Outputs**: `Out` (Type: `TEXT`)

---

## Usage

Click the **Coucou Xureil** button in the module window to emit `"coucou mr melon"` to connected text viewer or downstream nodes.
