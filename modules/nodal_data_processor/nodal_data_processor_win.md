# Nodal Data Processor Module

The **Nodal Data Processor** module provides a node-based visual graph editor for assembling, configuring, and executing modular data processing pipelines. It allows users to manipulate numerical signals and time-series data (such as fluorimetry curves, spectral datasets, or optical kinetics) in real time without writing code.

---

## Overview & Architecture

The module embeds an interactive node editor ([`DataNodeEditor`](file:///c:/Users/gerva/OneDrive/Documents/GitHub/Pipeline_creator_dev/modules/nodal_data_processor/data_node_editor.py)) inside a DearPyGui window. Each processing unit is a discrete node inheriting from [`DataProcessorBase`](file:///c:/Users/gerva/OneDrive/Documents/GitHub/Pipeline_creator_dev/modules/nodal_data_processor/data_processor_base.py).

When input data arrives (e.g. from an upstream CSV Reader, Sample Container, or Calculator), it flows through the connected nodes following graph topological order. Whenever a parameter is adjusted in a node's UI, the pipeline automatically re-processes the active sample with instant visual feedback downstream.

---

## Features

- **Visual Graph Construction**:
  - Connect node outputs to inputs with interactive Bézier links.
  - Right-click popup menu with fuzzy search to instantly spawn processor nodes.
  - Delete nodes/links via `DEL` key or contextual menus.
  - Anchor node representing global input stream (`X`, `Y`, `Labels`).

- **Real-Time Dynamic Execution**:
  - Automatically re-evaluates the active pipeline when parameters or connections change (`reprocess_last_sample()`).
  - Preserves labels, sample names, and UUIDs across processing steps.

- **Flow Serialization & Automation**:
  - **Save / Load Flows**: Persist entire node graphs and parameter configurations as JSON files (`flows/`).
  - **Remote Flow Control**: Automatically switch pipelines via upstream `CMD_DICT` commands containing `{"load_flow": "path/to/flow.json"}`.

- **Auxiliary Outputs & Metadata Superimposition**:
  - Processors can emit auxiliary curve series (e.g. fitted polynomial curves, baseline slopes) alongside the primary processed curve.
  - Auxiliary curves inherit parent sample UUIDs and names for synchronized plot updates and lifecycle actions (`select`, `unselect`, `rename`, `delete`).

## Technical Specifications

### Inputs

| Input Type | Supported Formats | Description |
|---|---|---|
| `IOTypes.SAMPLE` | `dict` (`{"name": str, "uuid": str, "x": list, "y": list, "labels": list, "action": str}`) | Primary sample data format. Executes pipeline on `"select"` or propagates lifecycle actions (`"unselect"`, `"rename"`, `"delete"`). |
| `IOTypes.DATALIST` | `dict` or `list` of `(x, y)` | Legacy 2D point array or dictionary with `x` and `y` lists. Auto-generates index `x` if omitted. |
| `IOTypes.CMD_DICT` | `dict` (`{"load_flow": "FvFm.json"}`) | Command to load and configure a saved flow graph remotely. Forwards commands downstream. |

### Outputs

| Output Name | Type | Description |
|---|---|---|
| `Processed Data` | `IOTypes.SAMPLE` | Transformed signal output dictionary containing processed `x`, `y`, `labels`, and sample metadata. Also streams auxiliary curves when emitted. |
| `Metadata` | `IOTypes.ANY` | Extracted numerical metrics, scalar parameters, or dictionary summaries generated by pipeline nodes. |

## Built-in Processors Catalog

The node editor automatically discovers processor scripts located in `modules/nodal_data_processor/processors/`:

### 1. Math (`processors/math/`)
- **Offset** (`offset.py`): Adds or subtracts constant offsets on `X` or `Y` axes, or shifts baseline to zero.
- **Divide Value** (`divide_value.py`): Scales or normalizes data by dividing `X` or `Y` by a scalar value.
- **Normalize** (`normalize.py`): Rescales `Y` values to a $[0, 1]$ or percentage range based on min/max.
- **Log10 X / Y** (`log10_x.py`, `log10_y.py`): Applies logarithmic ($\log_{10}$) scaling to input values.
- **Delta Calculator** (`delta_calculator.py`): Computes baseline subtraction from a single index or average over a range of indices.
- **Derivative** (`derivative.py`): Computes 1st ($dy/dx$) or 2nd ($d^2y/dx^2$) numerical derivative with support for custom/per-sample $dx$ and central difference precision preserving signal length.

### 2. Fluorimetry (`processors/fluo/`)
- **Fv/Fm** (`fvfm.py`): Computes maximal photochemical quantum yield of Photosystem II ($F_v/F_m = \frac{F_m - F_0}{F_m}$).
- **PhiPSII** (`phi.py`): Calculates effective quantum yield of PSII ($\Phi_{PSII} = \frac{F_m' - F_t}{F_m'}$).
- **NPQ** (`npq.py`): Calculates Non-Photochemical Quenching ($NPQ = \frac{F_m - F_m'}{F_m'}$).
- **rETR** (`retr.py`): Computes relative Electron Transport Rate based on incident light irradiance and quantum yield.

### 3. Fitting & Regression (`processors/fitting/`)
- **Linear Regression** (`linear_regression.py`): Fits a straight line ($y = ax + b$) and outputs slope, intercept, $R^2$, and auxiliary trendline curve.
- **Polynomial Regression** (`polynomial_regression.py`): Fits higher-degree polynomials with customizable degree and emits fitted auxiliary series.
- **Gaussian Deconvolution** (`gaussian_deconvolution.py`): Deconvolves complex multi-peak spectra/signals into individual Gaussian components ($G_1, G_2, \dots$) and total sum. Supports Auto Best Fit, Fixed Count, and Manual Target Centers with coverage assessment ($R^2$, % surface area coverage).

### 4. Filters & Slicing (`processors/filter/`)
- **Extract Time** (`extract_time.py`): Truncates or windows dataset to a specific time interval $[t_{min}, t_{max}]$.
- **Label Filter** (`label_filter.py`): Filters data points matching specific textual or phase label tags.
- **Crop** (`crop.py`): Slices dataset by range (from... to...) or trims edges (crop left / crop right) with unit choice (point indices or real X coordinates).
- **Smoothing** (`smoothing.py`): Versatile multi-mode signal smoother featuring Rolling Mean, Exponential Moving Average (EMA), Savitzky–Golay Filter (with automated crash safety sizing), Rolling Median (spike/outlier removal), Gaussian 1D filter, and Cumulative Moving Average.

### 5. Correction & Calibration (`processors/correction/`, `processors/tara/`)
- **Slope Correction** (`slope_correction.py`): Subtracts linear drift or baseline background slope.
- **Tara Processor** (`tara_processor.py`): Specialized calibration and baseline correction pipeline.

## Creating Custom Processors

To create a new processing node, add a `.py` file inside `modules/nodal_data_processor/processors/<category>/` inheriting from [`DataProcessorBase`](file:///c:/Users/gerva/OneDrive/Documents/GitHub/Pipeline_creator_dev/modules/nodal_data_processor/data_processor_base.py):

```python
from modules.nodal_data_processor.data_processor_base import DataProcessorBase
import dearpygui.dearpygui as dpg

class MyCustomProcessor(DataProcessorBase):
    name = "My Processor"
    category = "Custom"
    description = "Applies custom transformation to input signal."

    def __init__(self):
        super().__init__()
        self.gain = 2.0

    def process(self, x, y, labels=None):
        processed_y = [v * self.gain for v in y]
        metadata = {"max_val": max(processed_y) if processed_y else 0}
        return x, processed_y, labels, metadata

    def custom_ui(self, parent):
        dpg.add_drag_float(
            label="Gain",
            default_value=self.gain,
            parent=parent,
            callback=lambda s, a: [setattr(self, 'gain', a), self.trigger_reprocess()]
        )
```
